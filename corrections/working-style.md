## 27/10/2026 — Check issue labels before judging branch merge readiness

**Correct fact:** When asked about unmerged issue branches (e.g. watcher fix branches), read the GitHub issue's labels and latest comments first. Do not infer "finished, safe to merge" from a clean worktree, last-commit message or idle sessions.

**Lesson:** Claude said fix/73, fix/76, fix/90 looked finished and mergeable; the issues were held-for-review (#73, #90) and needs-human (#76). Branch state does not show review status.
